# Gothic Reliquary User Profile

A dark, gothic-inspired Toyhouse user profile featuring cathedral aesthetics, antique accents, elegant typography, and customizable content sections.

## Features

- Large cinematic hero banner
- Profile sidebar with:
  - Portrait
  - Basic information
  - Status section
  - Social links
- Large "About" section
- Featured characters gallery
- Loves & Do Not sections
- Content warning box
- Fully responsive Bootstrap layout
- No premium required

## Customization

Replace the placeholders with your own content:

- Username
- Profile image
- Hero background (optional)
- Social links
- About text
- Featured characters
- Likes / Boundaries
- Statuses
- Content warnings

Image placeholders use `placehold.co` and can simply be replaced with your own image URLs.

## Requirements

- Toyhouse WYSIWYG enabled
- HTML editing permissions
- Bootstrap support (included through CDN)
