SAKURA STREET — TOYHOUSE INSTALLATION

FILES
-----
1. index.html
2. catalog.html
3. styles.css

SETUP
-----
1. Create or choose the Toyhouse profile that will be the main café page.
2. Paste index.html into that page's HTML/profile content field.
3. Create a second Toyhouse character or literature page for the catalog.
4. Paste catalog.html into the second page's HTML field.
5. On both pages, paste styles.css into the Custom CSS field.
6. Copy the catalog page URL and replace CATALOG_TOYHOUSE_URL in the main HTML.
7. Copy the main profile URL and replace MAIN_PROFILE_URL in the catalog HTML.
8. Replace the placeholder images with direct image URLs you control.
9. Replace all href="#" placeholders with real links, or remove those anchors.
10. Keep the credit line unless you are the layout's author and choose another credit.

WHY TWO PAGES?
--------------
Toyhouse does not work like conventional web hosting. A separate local .html file cannot be
uploaded as a website page. The Toyhouse-friendly equivalent is to place the catalog on a
second Toyhouse character or literature page and link to that page. The catalog button opens
that Toyhouse URL in a new browser tab.

PREMIUM NOTES
-------------
This package is intended for Premium accounts because its styling belongs in Toyhouse's
Custom CSS field. The HTML contains only profile markup: no <html>, <head>, <body>,
<script>, or external CSS tags.

The CSS uses an ss- prefix to reduce clashes with Toyhouse's own classes and themes.
Font Awesome icon classes are used for the phone and back-arrow icons.

IMAGE HOSTING
-------------
The included placehold.co URLs are temporary visual placeholders. Replace them with image
URLs from a stable image host or your own Toyhouse-hosted image links where appropriate.
