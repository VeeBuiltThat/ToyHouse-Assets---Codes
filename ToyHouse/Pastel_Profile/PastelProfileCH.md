# Soft Pastel Character Profile

A clean, soft pastel Toyhouse character profile designed with rounded cards, gentle gradients, and an easy-to-read layout.

Perfect for original characters, comfort OCs, fantasy characters, and slice-of-life profiles.

## Features

- Soft pastel aesthetic
- Responsive two-column layout
- Character overview
- Basic information panel
- Color palette display
- About section
- Personality section with tags
- Likes & Dislikes
- Design Notes
- Character stat bars
- Relationship cards
- No premium required

## Customization

Replace the placeholders with your own content:

- Character name
- Quote
- Character image
- Basic information
- Personality
- Likes & Dislikes
- Design notes
- Stat values
- Relationship cards

The placeholder images can be replaced with any image URL.

## Requirements

- Toyhouse WYSIWYG enabled
- HTML editing permissions
