FREE-USER TOYHOUSE LAYOUT

This version is intended to be pasted directly into a Toyhouse profile HTML field.

It uses:
- Bootstrap grid and utility classes already available on Toyhouse
- inline style="" attributes
- ordinary anchor links
- no <style> block
- no JavaScript
- no external stylesheet
- no Premium Custom CSS

HOW TO USE
1. Open free_user_profile_HTML.txt.
2. Copy everything.
3. Paste it into your character or user profile HTML editor.
4. Replace all placeholder text and links.
5. Replace every placehold.co URL with your own direct image URL.
6. Keep or edit the credit line.

The “view collection” button scrolls to the catalog section on the same page.
The item buttons can link to other Toyhouse characters, tabs, galleries, or literature pages.
